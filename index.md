## Global Components

### Navigation (Persistent)
- **Position:** Fixed top, full width
- **Style:** Glassmorphism on scroll (backdrop-filter blur)
- **Logo:** "Lume Mia" (top-left)
- **Nav items:** "Menu", "Story", "Visit", "Contact" (top-right)
- **Behavior:** Transparent on hero, glassmorphism after scrolling past hero

### Grain Overlay (Persistent)
- **Style:** Static PNG overlay, mix-blend-mode overlay, opacity 0.08-0.12
- **Scope:** All sections

### Dotted Grid Pattern (Persistent)
- **Style:** CSS radial-gradient pseudo-element
- **Motion:** Subtle background-position drift on pinned sections
- **Scope:** All sections

### Magnetic Cursor (Desktop Only)
- **Effect:** Custom cursor that magnetically snaps to interactive elements
- **Implementation:** GSAP-powered, transforms only

---

## Component List

### Shadcn/ui Components
- Button (CTAs, form submit)
- Input (email form, contact form)
- Textarea (contact form message)
- Card (menu items, info cards)
- Separator (section dividers)

### Custom Components
- **CollageCard** — Rounded image card with shadow/border
- **CollageCluster** — Composite card with overlapping elements
- **TagChip** — Gold-accented tag pill
- **CircleText** — SVG textPath for circular typography
- **BotanicalOutline** — SVG stroke-only botanical icons
- **GrainOverlay** — Global grain texture overlay
- **DottedGrid** — CSS radial-gradient background pattern
- **MagneticCursor** — Custom cursor effect
- **GlassNav** — Glassmorphism navigation bar
- **SectionWrapper** — Pinned section container with ScrollTrigger
